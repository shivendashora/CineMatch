🎬 Movie Recommendation System

A machine learning-based Content-Based Movie Recommendation System that recommends movies similar to a user's selected title using the TMDB 5000 Movies Dataset.

Instead of relying on user ratings, this system analyzes movie content—including genres, overview, keywords, cast, and crew—to identify similar movies. The metadata is preprocessed and transformed using TF-IDF Vectorization, after which Cosine Similarity is used to compute the similarity between movies and generate accurate recommendations.
